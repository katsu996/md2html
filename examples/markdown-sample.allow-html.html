バックスラッシュによるエスケープ

*アスタリスク* のようにバックスラッシュを付けると、記法として解釈されずそのまま表示されます。

`バッククォート` や #見出し、~チルダ~ も同様です。

生HTML（既定ではエスケープされます）

md2htmlは既定でMarkdown中の生HTMLをエスケープします。 次の定義リストは生HTMLで書かれているため、既定の出力ではタグがそのまま表示され、 --allow-html 付きの出力でのみ定義リストとして描画されます。 Markdown記法の定義リスト（用語＋: 説明形式）は「定義リスト」の節を参照してください。

オレオ
クッキー&クリーム
リッツ
プレーンクラッカー

注釈・脚注

本文本文本文[1]。同じ脚注への複数参照[1]もできます[2]。

続きの行（4スペースインデント）も脚注に含まれます。

脚注番号は最初の参照順に付与され、未参照の定義は出力されません。 ラベル文字列はHTMLに出力されません（セキュリティ上の理由）。

定義リスト

用語の次の行を : で始めると定義リスト（<dl>）として描画されます。 用語と : 説明 の間は空行を入れません。

オレオ
クッキー&クリーム
リッツ
プレーンクラッカー
太字やコードを含む説明も書けます

単独の行に : を含む文（例: 注意: この文は段落のままです）は定義リストになりません。

md2htmlで対応していない記法（参考）

以下はQiita・DocBase・GitHubで使われることがある記法ですが、 md2htmlの現在のパーサー（marked）では専用のHTMLに変換されません。 サンプルとして記載しますが、出力HTMLでの表示崩れを確認するためのものです。

下線・ハイライト（Markdown標準外）

<u>下線</u> や <mark>ハイライト</mark> はMarkdown標準の記法ではなく、 生HTMLでのみ表現できます（--allow-html が必要です）。

数式・図（未対応）

LaTeX数式（$x^2$）、Mermaid、PlantUMLなどの埋め込みには対応していません。
