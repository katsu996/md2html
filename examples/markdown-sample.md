# Markdown記法サンプル

このファイルは md2html の動作確認用サンプルです。
[Qiita: Markdown記法一覧](https://qiita.com/oreo/items/82183bfbaac69971917f)と
[DocBase: Markdown記法と書き方](https://help.docbase.io/posts/13697)を参考に、
md2html（marked + GFM）が正しくHTMLへ変換できる記法を網羅しています。

動作確認:

```bash
pnpm run sample
# → examples/markdown-sample.html（既定: 生HTMLをエスケープ）
# → examples/markdown-sample.allow-html.html（--allow-html: 生HTMLを許可）
# ブラウザで開いて表示を確認してください。
```

## テーブル（GFM）

| Left align | Right align | Center align |
|:-----------|------------:|:------------:|
| This       |        This |     This     |
| column     |      column |    column    |
| will       |        will |     will     |
| be         |          be |      be      |
| left       |       right |    center    |
| aligned    |     aligned |   aligned    |

コロンの位置で配置を指定します。`:---` が左寄せ、`---:` が右寄せ、`:---:` が中央寄せです。

セル内では `コード` や **太字**、[リンク](https://qiita.com) も使えます。

| 記法 | 説明 |
|:-----|:-----|
| `**太字**` | **太字**になります |
| `*斜体*` | *斜体*になります |
| `~~取消線~~` | ~~取消線~~になります |

各行のパイプ記号の数は揃えてください（DocBase新エディターでは列数が合わないと正しく表示されません）。

## バックスラッシュによるエスケープ

\*アスタリスク\* のようにバックスラッシュを付けると、記法として解釈されずそのまま表示されます。

\`バッククォート\` や \#見出し、\~チルダ\~ も同様です。

## 生HTML（既定ではエスケープされます）

md2htmlは既定でMarkdown中の生HTMLをエスケープします。
次の定義リストは生HTMLで書かれているため、既定の出力ではタグがそのまま表示され、
`--allow-html` 付きの出力でのみ定義リストとして描画されます。
Markdown記法の定義リスト（`用語`＋`: 説明`形式）は「定義リスト」の節を参照してください。

<dl>
  <dt>オレオ</dt>
  <dd>クッキー&amp;クリーム</dd>
  <dt>リッツ</dt>
  <dd>プレーンクラッカー</dd>
</dl>

## 注釈・脚注

本文本文本文[^1]。同じ脚注への複数参照[^1]もできます[^日本語ラベル]。

[^1]: 注釈テキスト注釈テキスト注釈テキスト
[^日本語ラベル]: **太字**や`コード`、[リンク](https://qiita.com)を含む脚注です。

    続きの行（4スペースインデント）も脚注に含まれます。

脚注番号は最初の参照順に付与され、未参照の定義は出力されません。
ラベル文字列はHTMLに出力されません（セキュリティ上の理由）。

## 定義リスト

用語の次の行を `: ` で始めると定義リスト（`<dl>`）として描画されます。
用語と `: 説明` の間は空行を入れません。

オレオ
: クッキー&クリーム

リッツ
: プレーンクラッカー
: **太字**や`コード`を含む説明も書けます

単独の行に `: ` を含む文（例: 注意: この文は段落のままです）は定義リストになりません。

## md2htmlで対応していない記法（参考）

以下はQiita・DocBase・GitHubで使われることがある記法ですが、
md2htmlの現在のパーサー（marked）では専用のHTMLに変換されません。
サンプルとして記載しますが、出力HTMLでの表示崩れを確認するためのものです。

### 下線・ハイライト（Markdown標準外）

`<u>下線</u>` や `<mark>ハイライト</mark>` はMarkdown標準の記法ではなく、
生HTMLでのみ表現できます（`--allow-html` が必要です）。

### 数式・図（未対応）

LaTeX数式（`$x^2$`）、Mermaid、PlantUMLなどの埋め込みには対応していません。
